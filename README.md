# NG KOMBAT — C# e .NET

Projeto desenvolvido em C# utilizando .NET Console como atividade prática de lógica de programação.

## Sobre o projeto

O NG KOMBAT é um jogo de batalha executado no terminal, desenvolvido com o objetivo de aplicar conceitos fundamentais da linguagem C# em uma aplicação prática.

Durante o jogo, o jogador enfrenta diferentes adversários em uma sequência de batalhas, podendo escolher entre ataques, defesa ou sair da partida.

## Funcionalidades

* Sistema de batalhas por fases
* Cinco adversários com diferentes quantidades de HP
* Ataques de soco, chute e Special Move
* Sistema de defesa
* Controle de pontos de vida
* Ataques aleatórios dos inimigos
* Sistema de vitória e derrota
* Opção para sair do jogo
* Possibilidade de iniciar uma nova partida
* Validação das opções escolhidas pelo usuário

## Conceitos de C# utilizados

O projeto foi desenvolvido para praticar diversos fundamentos da linguagem:

* `Console.ReadLine()`
* `Console.WriteLine()`
* Variáveis
* Conversão de dados
* `if`, `else if` e `else`
* `for`
* `while`
* `do...while`
* Arrays
* Métodos
* `switch`
* Operadores matemáticos
* Operadores lógicos
* Geração de números aleatórios
* Validação de entradas
* Comentários no código

## Tecnologias

* C#

## Objetivo acadêmico

Este projeto foi desenvolvido durante minha formação em Análise e Desenvolvimento de Sistemas com o objetivo de fortalecer o raciocínio lógico e colocar em prática os principais fundamentos da programação em C#.

## Execução

Para executar o projeto, é necessário ter o .NET SDK instalado.

No terminal, dentro da pasta do projeto, execute:

```bash
dotnet run
```

## Evolução do projeto

Este projeto representa a primeira etapa do desenvolvimento do NG KOMBAT. Nas atividades seguintes, a aplicação foi evoluída com Programação Orientada a Objetos e posteriormente com persistência de dados em arquivo TXT.
